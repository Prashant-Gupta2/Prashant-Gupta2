### StockFlow

### Mini Online Test

Students can change an answer before submitting a test and return to their results later. The Express API saves selections to the active attempt in MongoDB, scores answers on the server, and lists completed attempts newest first.

[Repository](https://github.com/Prashant-Gupta2/mini_online_test) · [Answer saving and scoring](https://github.com/Prashant-Gupta2/mini_online_test/blob/main/backend/controllers/testController.js) · [Open demo](https://mini-online-test-six.vercel.app/login)
